在 Flower 中添加并使用模型

推荐输入法帮写使用 Chat Completions：这是广泛兼容的单次文本对话接口。
Responses 是另一种请求和响应格式，并不表示模型更好；帮写不需要其工具/远程会话能力。
常规界面默认 Chat；原有 Responses 连接保留，不会自动改协议，可在高级设置中检查。

第一步：准备服务商 API
1. 在服务商官网创建用于模型标准 API 的密钥，并确认账号有对应模型权限及额度。
2. 网页聊天会员或 Coding Plan 订阅不一定可用于普通模型 API。
   智谱 https://open.bigmodel.cn/api/v1 是 Coding Plan 入口，套餐有适用工具限制，
   Flower 不伪装受支持工具，也不保证能使用该套餐额度。
   通用按量标准 API 基址为 https://open.bigmodel.cn/api/paas/v4，需匹配的密钥/权限。
   只有 Coding Plan 账号/密钥，并不代表可以在 Flower 使用套餐生成。
   Coding 入口获取不到模型目录时可查官方支持范围；手填 ID 只补模型参数，
   不能赋予账号权限。HTTP 500 本身不能区分套餐限制与服务端故障。
   新提示会保留 HTTP 及可安全解析的纯数字业务码，供服务商排查，不显示原始响应正文。
3. DeepSeek 常规 API 基址为 https://api.deepseek.com，使用 Chat Completions。
   不要为它选择 Responses。OpenAI 常见基址为 https://api.openai.com/v1，协议依模型文档。
4. 填 API 基址，不填最后的 /chat/completions、/responses 或 /models。
   程序按操作追加路径，不会替你补 /v1；版本前缀以服务商文档为准。
5. 只支持 HTTPS、ASCII 域名/IPv4及可选端口；不支持 URL内密码、查询参数、编码路径。
   不要把密钥贴到聊天、截图、API地址或模型名称里。

第二步：连接与选择模型
1. 打开设置 → AI 功能 → 模型 API，或帮写中的“管理模型 API”。
   窗口默认按显示器 DPI 放大并限制在工作区内；小屏可滚动，高级设置可折叠。
2. 新建连接，填写便于识别的名称、API 基址及新密钥。
3. 主动点击“获取模型列表”。此动作只向当前基址的 /models 发送认证GET，
   不发送你的要点/正文，不调用生成，不自动保存密钥或选择第一个付费模型。
4. 从模型下拉中选要用的文本模型。接口调用仍必须有模型 ID，列表帮助你免于手填。
   目录获取成功不代表该模型能生成、价格已确认或账号额度无限。
5. 并非所有服务商支持标准模型目录。获取失败或目录没有目标模型时，
   在高级设置中按服务商文档手动填写准确模型 ID；不要猜一个名称或复用别家的模型名。
6. 若使用只支持 Responses 的服务，在高级设置选择它；原连接不被静默更改协议。

第三步：保存并使用
1. 选好模型后点击“保存并使用”。这一按钮安全保存密钥和连接，并明确设为当前使用。
2. 如果未输入新密钥，只能沿用同一已保存连接目标的受保护密钥；新目标必须重新输入。
3. 密钥失败不应用连接；连接保存失败会告知实际结果，不把部分成功当作已应用。
4. 看实际当前连接/模型提示。它表示选择已生效，不表示已经完成真实生成验证。
5. 密钥只放当前 Windows 用户凭据管理器，不进普通设置 JSON，也不显示旧明文。
   修改地址或协议不把旧密钥转发给新目标。
6. 删除密钥在高级设置中独立确认；删除连接不等于撤销服务商密钥。
   不再使用的密钥还应在服务商官网撤销。

第四步：第一次帮写
1. 先在设置 → AI功能中勾选“启用在线AI功能”（默认关闭），保存后立即生效，无需重新切换Flower。
   默认单独组合 Ctrl+Alt 后松开打开帮写，输入不含隐私的要点，例如“通知同事明天下午三点开会”。
2. 点击生成草稿，核对确认框中的实际地址、模型和协议后再发送。
3. “不再提示”只在勾选后点击“发送”才保存；取消、Esc或关闭不会保存。
   设置 → AI功能 → 恢复帮写发送确认，可恢复提示。
4. 打开窗口、保存设置或获取列表不会自动生成；每次生成都需主动操作。
5. 预览后可复制；有可靠安全绑定时才可明确插入，不自动改写宿主文档或发送消息。

第五步：快捷润色
1. 先启用AI功能页的在线AI总开关；模型保存不会自动开启在线AI。
   润色还须在在线 AI 设置中开启子开关，可核对目标、调整风格/字形或关闭。
   以前明确保存的关闭选择仍保留。只有主动选区并按快捷键才外发，不会监听或自动上传选区。
2. 重新切换到 Flower，使输入法读取最新配置；旧激活快照不会自动改发新目标。
3. 在安全可读写的文本框主动选中1–500字，默认按 Ctrl+Space。
4. 原文在生成和预览期间不变，只有点击“使用”才可能替换；Enter/Space/数字键不采纳。
5. 若旧激活快照与当前连接不同，不会暗发新目标，需重新切换 Flower。
6. 两个快捷键可在设置中直接按键录入，不再限于预设下拉列表。
   纯修饰组合单独按下后松开才触发，中途按过其他键不触发。
   Ctrl+Space可能与系统输入法热键冲突，Flower不修改系统热键，也不注册全局快捷键。

失败提示与隐私
- HTTP400/404/405/422等先检查 API基址、协议、模型权限与参数，不能统称“响应格式无效”。
  401/403检查密钥/权限；402检查额度；429可能限流；5xx可能是服务端问题。
  不要关闭证书校验、伪装支持工具、把密钥写进URL或随意更换收费入口来绕过。
- 智谱1302为账号速率限制、1305为服务过载；可选有限重试默认关闭，
  只沿用明确标准智谱错误且无正文的原规则，不扩展为其它接口未知429的付费重发。
- Flower不自动买额度、换模型/账号；付费也可能限流。保存、获取目录与推理成功是三件事。
- Flower默认不保存正文和生成历史，不上传周围正文/窗口标题/路径/词典。
  服务商的留存、训练和地域处理依其条款，Flower不能保证零留存。
  停止不能撤回已经发送的文本，服务商可能继续处理计费。不要发送敏感信息。
