当前开发版已支持自行配置 Chat Completions / Responses 模型 API，
程序内帮助的唯一正文为 model-api-setup.txt，请优先阅读该文件。
以下“不需要填写地址/模型名”等表述仅适用于旧版，不代表当前界面。

在旧版 Flower 中使用 GLM-4.7-Flash

不需要下载生成模型、安装 Python、编写代码或购买 Coding Plan。
Flower 使用智谱开放平台的模型标准 API。当前免费政策可能调整，
实际可用模型、账号权限和调用额度以智谱官网为准。

第一步：注册并登录智谱开放平台
1. 在浏览器中打开官网：https://open.bigmodel.cn
2. 点击“注册/登录”，按官网提示完成账号注册。
3. 如果官网要求补充账号认证或权限信息，请按当前页面提示处理。
   Flower 不会替你提交身份信息，也不要求你把账号密码或证件发给我们。

第二步：创建正确类型的 API 密钥
1. 进入个人中心或控制台，找到“API Keys / API 密钥”。
2. 选择“模型标准 API”对应的密钥管理，不要使用个人/团队 Coding Plan 套餐密钥。
   官方说明这些产品类型的密钥互不通用。
3. 创建一个新密钥，可以取名“Flower”，复制完整的密钥。
4. 复制的是密钥本身，不是名称、账号密码或 Bearer 前缀。
5. 不要把密钥贴到聊天、截图、问题反馈或代码仓库。
   如果泄露，请到官网删除/撤销旧密钥，再创建新密钥。

第三步：在 Flower 保存密钥
1. 打开“AI 帮写”的连接配置，或设置中的“在线 AI 设置”。
2. 将密钥粘贴到密码式输入框，点击“保存密钥”。
3. Flower 用当前 Windows 用户的凭据管理器保护密钥，
   不需要填写 API 地址或模型名，也不会显示已保存密钥的明文。
4. 保存密钥本身不联网、不消耗调用额度，也不会自动生成正文。
   模型当前标为免费，不要为本功能盲目购买套餐或充值；
   若官网提示账号限制，请先检查对应原因及当前政策。

第四步：第一次使用帮写
1. 打开 AI 帮写；在有效 Flower 输入上下文中默认按 Ctrl+Shift+1。
2. 输入一段不含隐私的测试要点，例如：
   “给同事写一条礼貌通知：明天下午三点在会议室开会，请准时参加。”
3. 选择语气、目标长度和输出字形，点击“生成”。
4. 阅读并确认本次在线发送告知，等待结果。
   确认框中的“不再提示”默认不选；勾选后再点“发送”会记住当前模型的同意。
   点取消或关闭不会记住。需要恢复时，到设置的“AI功能”选择恢复帮写发送确认。
   即使不再提示，仍只有你主动生成才会发送；更换服务商/模型后需重新确认。
5. 预览后选择复制；有安全绑定的空插入点时，才可明确插入。
   打开窗口和生成完成都不会自动向宿主写入或发送消息。

第五步：启用快捷润色
1. 在 Flower 设置中打开“在线 AI 设置”。
2. 选择通顺、正式或简洁，以及跟随当前字形、简体或通用繁体。
3. 阅读外发说明，勾选允许按润色快捷键将所选文本发送至智谱润色，并保存。
4. 按设置提示重新切换到 Flower，使输入法侧读取新参数。
5. 在支持的安全文本框中主动选中 1–500 字，默认按 Ctrl+Shift+2。
6. 原文旁出现润色候选浮层，生成期间原文不变；完整结果出来后，
   点击“使用”才替换原选区，不满意直接取消。
7. 未声明安全范围、不支持读取或只读的宿主会被明确拒绝；
   不会自动读取剪贴板、全文或聊天历史。

常见问题
• 提示密钥无效或无权限：
  检查是否复制完整、是否误用 Coding Plan 密钥、密钥是否已撤销，
  并在官网确认该账号具有模型标准 API 的使用权限。
• 提示额度不足：
  先查看官网账号状态和模型当前价格，不要直接按提示购买其他付费模型。
• 提示账号速率限制（1302）：
  检查账号控制台模型并发限制，也检查是否有其他应用同时使用同一账号。
• 提示模型服务繁忙（1305）：
  这是模型当前整体访问压力，可能与你的调用频率无关，稍后再试。
• 可选等待重试：
  帮写连接配置可主动开启“繁忙时自动等待后重试”，默认关闭；
  仅在明确1302/1305且没有正文时最多重发2次，总等待/请求不超过90秒，
  随时可停止，每次重发均可能计额。不自动切付费模型。
• 提示密钥类型不匹配、套餐限制或周期用量上限：
  先在控制台核对模型标准API密钥及账号权限/额度，不要连续点击重试。
• 提示网络、证书或超时：
  检查能否正常访问官网及本机网络设置，不要关闭证书校验。
• 生成中停止：
  客户端会尽力取消并拒绝晚结果，但已发送文本无法撤回，
  服务商仍可能继续处理或计入额度。

隐私与费用提醒
默认快捷键为 Ctrl+Shift+1 / Ctrl+Shift+2，可在设置中分别自定义；
支持Ctrl+Shift加字母、数字或F1–F12，Ctrl+Shift+F保留简繁切换。
保存快捷键后重新切换Flower生效，旧Ctrl+1/2不再作为AI快捷键。
只有明确生成或已授权后的润色快捷键才发送本次文本及必要指令。
Flower 默认不保存正文或生成历史，但不能代替智谱保证零留存或不训练。
不要提交机密、密码或他人敏感个人信息。不要混用付费型号 GLM-4.7-FlashX。
真实质量和速度取决于服务与网络，不能由安装成功或假传输测试保证。
