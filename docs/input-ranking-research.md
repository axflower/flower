# 常用字词排序机制与本轮改进

## 公开机制的对照

| 信号 | 公开资料 | Flower当前行为 |
| --- | --- | --- |
| 基础词频/静态模型 | libime的UserLanguageModel先取LanguageModel分数，再组合用户历史概率 | 词库原weight及有界日常prior；长句还有词边数量、缩写、字数等图评分 |
| 个人动态词频 | QQ拼音官方帮助说明根据使用频率调整词序，造词和重复选择会影响后续候选 | 按用户确认，保持同一raw每次选择普通完整候选前移一位，不改成置顶/加速 |
| 上下文和用户历史 | libime HistoryBigram可按前词计分，Rime保存用户词条/动态提交信息 | 不采集周边正文；个人排序与可选离线AI纠错独立 |
| 固定首词/固顶 | QQ帮助把动态词频、首词固定、候选固顶分别介绍 | 本轮不新增固顶，不能把相邻前移误称统计词频模型 |

## Flower中已核对的问题

实际builtin固定46项探针中，常见全拼“问题、世界、时间、工作、现在、知道、已经、健康、
中国、你好、是、的、一、我、你”均首位；这不能外推所有字词都符合使用概率。

独立输入`n`时，旧规则把合法完整读音`n`的“嗯、哽、唵”等整层放在首字母补全之前，
使“你”落到第10。0.4.18将辅音单字母的两类单字统一按已有词库权重排序，
“你”可在首页，“年”等其他高频字也保留竞争；不硬编码“你”永远首位。
元音完整读音优先、规范reading、一个raw字母消费和`l`的“了、来”保持。

另一些顺序来自数据本身：`fll`的奉礼郎129高于法拉利44，`mdl`的灭滴灵513高于麦当劳127，
`chongdian`的“重点”来源权重12694高于“充电”304。这涉及不同类别及读音级频率缺口，
不能给个别品牌强加权或删合法读音来假装完成通用排序。本轮保留这些边界，
没有下载或宣称拥有新的统计语料。

## 微信个人排序的差异与修复

用户确认浏览器、记事本能更新普通候选顺序，微信同一raw连续选择仍不动。
此前已确认微信会返回S04（未声明范围）。0.4.17的AI可以走自定义窗口兼容路径，
普通学习却仅支持声明安全范围或原生Edit/RichEdit兼容；这构成生产策略差异。

0.4.18让普通学习复用现有未声明范围兼容检查，并保持每次只前移一位。
设置“兼容未声明范围的应用”同时控制两者；AI总开关不关闭普通学习。
焦点/身份/style/原生密码掩码、敏感与异常接口拒绝均保持。
详细合同见[组合拼写与普通学习兼容](../design/composed-spelling-and-learning-compatibility.md)。

隔离自定义窗口和真实TSF context验证不能代替用户微信现场，实际宿主仍应复测。
未声明且没有标准密码标记的自定义敏感框可能无法识别；可关闭兼容恢复严格限制。
