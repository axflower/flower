## 原因与范围

在真实内置词库、默认个人快照下，`huiyi` 首项为“会议”，第二项为“回忆”。
数字 2 选择能够产生规范 `hui'yi/回忆` 学习事件，旧评分第一次只增加 120 分，
不足以抵消两词基础分差。因此生成/保存排序记录不能证明生产综合评分会前移。
本次没有为 `huiyi` 添加人工 prior 或改来源权重。

用户选择继续综合评分，增强个人频次与近期加分，而非恢复每次相邻交换。
新逻辑在这组固定真实词库对照中一次选择即可成为首项；大量既有个人历史、不同前文、
高低频差仍可能改变结果，不承诺任意词一次置顶，不重置用户历史或显式开关。

## 学习链路

- `one_numeric_builtin_selection_changes_close_word_ranking_without_absolute_order`：
  真实 builtin 数字 2 提交“回忆”，新的评分快照下成为首项；另用极端词频差控制验证非绝对置顶。
- `native_builtin_huiyi_numeric_feedback_is_immediate_and_durable`：
  真实 TSF 文档和生产按键、明确安全 scope、隔离 worker 保存；同 context 下次为首，
  worker drain 后新服务/新 Store 回读仍为首，次数精确为 1。
- `native_acp_builtin_huiyi_numeric_feedback_in_safe_text_store`：
  可写 ITextStoreACP 桥接生产数字选择与空格提交，读回“回忆回忆”。
  它覆盖浏览器类 TSF 文本存储形态，不冒充实际 Edge 桌面已经验证。
- 个人统计与并发/代次/清空/边界集成 14 项通过，用户词典 34 项通过、1 个 helper 默认忽略。
  延长近期权重后同步覆盖序号溢出重基准，仍有效的 1100 次活动年龄不被意外清零。

## 固定公开日常对照

`examples/ranking_probe.rs` 只用固定公开输入，不读取用户词典或宿主正文。
以下是无个人历史/无前文的同机真实 builtin 对照，不是自然语料总体准确率。

| keyi | 可以、柯怡、可疑 | 可以、可疑、刻意 |
| yiyi | 意义、一一、一医 | 意义、一一、异议 |
| yijing | 已经、义井、一经 | 已经、一经、意境 |

“师姐”等也在固定列表中前移；原始词和规范读音仍可完整查询、翻页提交。
人工交流 prior 有界且按完整读音/原词匹配，不是统计词频。`huiyi` 默认顺序不变，
选择后才靠个人统计改变。“是、的、一、问题、时间、现在、工作、知道”等对照的首项保持。
没有扩大解码预算、硬编码例句或删除不符合本次默认习惯的合法词。
