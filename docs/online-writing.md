# 在线 AI 帮写与润色

本文适用于0.5.4测试版的在线写作功能，不表示旧安装包已经包含这些改动。
自定义接入契约见`design/custom-model-api.md`，写作/安全写回流程见
`design/ai-writing-and-inline-polish-0.5.0.md`，验证状态见`docs/windows-validation.md`。

## 自行配置模型 API

设置 → AI 功能 → **模型 API** 可管理多组连接，也可从帮写的“管理模型 API”进入。
每组填写配置名称、协议、HTTPS API基址、准确模型ID，明确选择当前使用的连接。
首期支持 **OpenAI兼容 Chat Completions** 和 **Responses（HTTP/SSE）**；
不支持原生Anthropic Messages、WebSocket、OAuth订阅登录、工具、图片或自定义请求头。
模型品牌相同不代表协议相同，请以服务商实际接口文档为准。

API基址示例：`https://api.deepseek.com`、`https://api.openai.com/v1`、
`https://open.bigmodel.cn/api/paas/v4`。不填最终`/chat/completions`或`/responses`，
Flower按协议追加，不会强行补`/v1`。首期只支持ASCII域名/IPv4和可选端口的HTTPS，
不支持HTTP、IPv6文字地址、URL用户名密码、查询/fragment、编码路径或点路径段。
一个连接对应一个模型，同一服务商的多个模型可建成多组连接。

常规界面默认使用兼容面更广的Chat Completions，Responses放在高级设置，
不会擅自更改已有连接协议。输入连接和密钥后主动“获取模型列表”，从下拉选择模型；
不支持标准目录的服务在高级设置手动填写模型ID。ID仍是调用必需参数，并非可以省去，
anywork的自定义模型也保留手填入口。目录GET不发送正文，不等于推理测试或额度保证。

点击“保存并使用”安全保存密钥及连接，并明确设置当前模型；回读选择后才提示应用成功，
仍标明未做真实调用验证，不把配置成功等同模型可生成。未输入新密钥时，
仅可复用同一已保存连接目标的凭据；新地址/协议不能把旧目标密钥转发过去。
已有密钥不显示明文。
删除连接不自动撤销服务商密钥，提供独立“删除密钥”确认；服务商官网也应撤销不再使用的密钥。
打开、选择、保存和删除配置/密钥均不请求模型。具体步骤与程序内帮助共用
[`model-api-setup.txt`](model-api-setup.txt)。

密钥由Windows当前用户凭据管理器保护，不放进普通设置JSON，不通过Flower服务器中转。
同用户权限下的其他程序仍可能访问凭据，这不是抵御系统已被攻破的保险箱。
不要把真实密钥贴到聊天、截图、反馈、接口URL或代码仓库。
Flower不代购、不充值、不内置共享密钥；费用和模型权限由用户与服务商约定。
付费也可能限流，保存配置不表示连通或质量已经验证，不支持接口专有参数的自动猜测/降级。
旧配置缺新字段时只读沿用原智谱连接及旧凭据槽，不自动迁写；新建连接不继承旧密钥。

DeepSeek的常规入口`https://api.deepseek.com`应使用Chat，不用Responses。
智谱`https://open.bigmodel.cn/api/v1`属于Coding Plan，官方限制适用工具环境，
不能因其他软件支持配置就认为Flower可用套餐额度；本程序不伪装工具身份。
标准按量模型入口为`https://open.bigmodel.cn/api/paas/v4`，需要匹配的密钥与模型权限，
不会为解决错误自动替换入口、转移密钥或产生付费请求。
手填模型ID不增加套餐权限；目录无法获取也不能单独判定生成接口是否可用。
Coding入口未知错误会显示HTTP状态与可解析的纯数字业务码（不显示原始message），
便于向服务商咨询；仅凭HTTP500不能断言是套餐拒绝或某个请求参数错误。

## 使用

先在设置 → AI功能中勾选“启用在线AI功能”，保存后立即生效，无需重新切换Flower。
该总开关默认关闭（旧配置缺字段也关闭），同时控制帮写与在线润色，
不影响离线AI纠错。保存模型或获取目录不会替你开启总开关。
关闭后已开帮写窗口也不能再次生成，已发送文本则无法撤回。

- 默认单独组合`Ctrl+Alt`后松开打开帮写，在独立窗口填写1–500字要点，主动点击生成草稿。
- 确认框显示实际接口、协议和模型。“不再提示”默认未选，仅勾选并发送才保存；
  取消、Esc或关闭不保存。仍需主动生成，不会打开窗口就发文本。
  设置 → AI功能 → 恢复帮写发送确认，可恢复提示；更换发送目标后重新确认。
- 润色子开关默认开启，已有明确保存的关闭选择保留；只有在线AI总开关也开启才可使用，
  可在“在线AI设置”调整风格/字形或关闭。
  只有主动选择安全文本并按快捷键才外发，不会自动监听或上传选区。
  重新切换Flower读取新快照；旧激活快照与当前连接不符时拒绝发送，不静默改发新目标。
- 在安全可读写的文本框主动选中1–500字，默认`Ctrl+Space`显示原文旁非激活候选。
  原文在生成和预览时不变；只有点击“使用”才重核并尝试替换，Enter/Space/数字键不采纳。
- 帮写`Ctrl+Enter`生成，Esc先停止否则关闭。没有可靠绑定时可复制后手动使用；
  不读剪贴板、不自动读周围正文、不能证明安全的选区不捕获。
- 在设置快捷键分组点击录制并直接按组合键，支持不同修饰键、主键及纯修饰组合，
  不再限于下拉预设。纯组合单独按下后松开触发，中途按其它键取消。
  保留Ctrl+Shift+F简繁切换；保存后重新切换Flower生效，不注册全系统热键。
  Ctrl+Space可能与系统输入法热键冲突，本程序不修改系统设置。

## 外发、费用与失败

每次任务使用一份固定连接快照：确认目标与实际发送目标一致，期间改连接须重新生成。
只外发本次明确提供的要点/安全选区及必要任务指令，不上传周围正文、窗口标题、路径、
词典或输入历史。Flower默认不保存正文/结果历史，不将其用于词典或排序学习。
服务商可能留存、训练或跨地域处理文本，以其条款为准，Flower不保证零留存或不训练。
Responses请求使用`store:false`且不续接远程会话，这不替代服务商隐私承诺。

停止/关闭会取消客户端请求并拒绝晚结果，但无法撤回已发文本，服务商可能继续处理计费。
失败不自动换模型/账号/供应商。未正常结束、拒绝、工具调用或超过800字的结果不能直接应用。
Chat要求正常stop加DONE；Responses要求完整completed终态及正文快照一致，EOF不算成功。

可选“繁忙时自动等待后重试”默认关闭，仅当前帮写窗口有效；只对智谱明确1302/1305、
尚无正文时在90秒总预算内最多重发2次。它不扩展为对其它接口未知429的自动付费重发。
进程内并发门禁不覆盖其他宿主进程/同账号应用；付费服务也不能保证无繁忙或限流。

## 验证边界

固定合成JSON/SSE、注入Store及自有窗口只证明协议和接线，不证明真实模型质量、
国内网络、账号权限、价格或所有宿主兼容。没有显式测试凭据时不发真实推理请求，
不为测试读取现有用户凭据。源码变化不自动更新旧`dist`或正在使用的DLL；以实际交付版本为准。
