<h1 align="center">Flower</h1>

<p align="center">轻巧、离线、尊重隐私的 Windows 拼音输入法。</p>

Flower 希望让中文输入回归简单：打开应用、切换输入法，就能用拼音写下想说的话。
不需要账号，不依赖云端服务，也不上传输入内容。

## 功能

- **全拼输入**：输入 `nihao`，选择“你好”；支持用 `'` 明确区分音节。
- **首字母简拼**：输入 `nh` 查找“你好”、`zg` 查找“中国”，与全拼共用候选和选词操作。
  仅输入一个字母也有单字候选，例如 `l` 显示“了、来、里、两”等。
- **混合拼音**：可以逐音节组合全拼和首字母，例如 `shenmeys` 查找“什么意思”。
  支持有界跨词组合补充，例如 `zheshism` 查找“这是什么”，不为例句硬编码词条。
- **常用短语**：补充日常交流表达，例如 `wan` 可查找“我爱你”，同时保留全拼候选。
- **Shift 中英文切换**：单独按 Shift 将未提交内容按原拼音上屏并切到英文，再按恢复中文。
- **连续选词与组句**：可以一次选择完整词句，也能分段选词、退格撤回或取消输入。
- **网络与口语表达**：内置803条项目人工短语，覆盖“情绪价值、搭子、显眼包、
  绷不住、绝绝子”等网络表达及日常沟通；0.4.20新增648条，其中518条此前未收录。
- **拼音内部编辑**：候选首项时按左键移动拼音光标，右键先移回末尾，再继续选择候选；
  支持在光标处插入、退格和 Delete。
- **分类离线词库**：默认加载 THUOCL 11 类词表、词级读音补充和儿化词表，
  相对当前基础及人工短语层补充 80,667 个词对，包含“法拉利、麦当劳、微信”等词；
  保留每类来源、许可及覆盖报告，未获得可靠读音的多音词不猜读。
- **个人词典**：通过命令行导入、导出UTF-8 TSV词条，设置窗口可按需启停专业词库。
  [格式、示例与操作步骤](docs/distribution.md#用户词典与设置)。
- **可选登录自启动**：安装完成页可勾选“开机自启动”，登录时静默启用后退出，
  不打开设置、不改变系统默认输入法；可在开始菜单关闭。
- **本地选词记忆**：成功选中的字词前移一位，默认保存于本机，重启后保留；
  提供关闭和清空入口，不联网同步。
- **逐段组词记忆**：词库没有“新加卷”时，输入 `xinjiajuan` 并依次选择“新、加、卷”，
  完整提交后自动记为本地词，下次全拼或简拼即可选择；取消或未完成的输入不记忆。
  关闭记忆停止新增，清空学习会删除自动词，但保留手工导入的个人词条和专业词库。
- **内置离线 AI 纠错（实验）**：完整包提供本地模型，输入停顿后补充带 `✓ AI`
  标识的纠正候选，由你选择；新默认开启、可关闭，不自动改文档，不记录 AI 选词学习。
  支持满足模型门槛的单次全拼误输修复，包括字母替换、漏打、多打和相邻交换。
  默认兼容微信等未声明输入范围的应用，可在设置关闭；明确密码/PIN/私密仍拒绝，
  但应用未声明的自定义敏感框可能无法识别，不读取聊天历史或周边正文。
  [分类复测说明](docs/pinyin-and-ranking-testing.md)涵盖拼音、汉字、常用词及选词记忆。
- **中文标点**：中文模式输出 `，。？！` 等中文标点、成对引号，英文模式仍直通。
- **原生卡片式设置**：分区管理候选外观、离线AI、本地学习和专业词库；
  支持页大小和主题调整，以及键盘、鼠标选词。
  短候选紧凑单行显示，长句自动换行完整展示；按词长和可用宽度自适应每页数量，
  窗口内不重复显示拼音。
  0.4.19 同屏输入更新保持候选窗可见，不再随每次音节变化反复隐藏、显示。
   不显示翻页符号和页码，高亮为抗锯齿圆角背景，文字末尾保留少量留白，键盘翻页仍可用。

## 开始使用

Flower 当前支持 **Windows 10 / 11 x64**。使用构建产物中的 EXE 安装器，或按
[分发与安装说明](docs/distribution.md)使用 ZIP 包。

1. 安装 Flower；若已安装旧版，先按分发说明安全卸载，不覆盖正在使用的 DLL。
2. 在普通用户桌面，从开始菜单运行 **“启动 Flower”**。
3. 按 `Win + Space` 切换到 Flower，在文本框中输入拼音并选择候选。

Flower 不会自动替换默认输入法。保存设置或修改用户词库后，请重新切换到 Flower 生效。

### 常用操作

| 操作 | 按键 |
| --- | --- |
| 选择当前高亮候选 | `Space` |
| 选择对应编号候选 | 数字键或鼠标点击 |
| 下一页 / 上一页 | `+`（或 `=`）/ `-`，也支持数字小键盘加减 |
| 候选首项时编辑拼音光标；回到末尾后继续选择候选 | `Left` / `Right` |
| 删除光标前拼音；起点时撤回上一段选词 | `Backspace` |
| 删除光标处拼音 | `Delete` |
| 取消当前未提交的输入 | `Escape` |
| 原拼音上屏并切换中英文 | 单独按下再松开 `Shift`，不影响 Shift 组合键 |

首字母简拼按每个音节的第一个字母输入，也可以与完整音节组合输入。
离线组句不等同于语言模型，遇到歧义时可以自行选词。

安装器固定将程序载荷和卸载器放在 Program Files 下的 Flower 目录，不提供自定义路径。
完成页默认勾选“启动 Flower”，仅启用当前用户输入配置，不打开设置；可用 Win+Space 切换。

## 隐私与当前状态

输入过程离线运行，无账号、无遥测、无云候选。选词顺序默认仅保存在本机，可关闭或清空；
密码、私密或无法确认安全的输入范围不会记录学习。

Flower 仍处于早期开发和兼容性验证阶段。测试安装包尚未签名，不同应用、DPI、安装及
升级场景仍需持续验证；自动测试通过不等于所有 Windows 宿主均已通过实测。

遇到问题时，请提供 Windows 版本、应用名称、Flower 版本、复现步骤及实际现象。
请勿提交私人文档、密码或其他敏感输入内容。

## 开发与贡献

Flower 使用 Rust 实现，Windows 平台通过 TSF 接入系统。欢迎提交问题、改进词库、
补充兼容性反馈或贡献代码。

公开字词数据独立维护于[flower-dict](https://github.com/axflower/flower-dict)，
Flower通过GitHub依赖消费`flower-dict 0.2.0`，Cargo.lock固定提交`d01e9ac5`；来源与验证见[接入说明](docs/dictionary-crate.md)。Flower不保留第二份可编辑词库。
其他输入法也可使用其静态TSV、分类元数据及零拷贝Rust迭代接口；
它不依赖Flower引擎或Windows。词库数据、来源/许可、生成脚本的修改请在该仓库进行。
本机用户词典、自动词记忆和个人排序仍归本输入法管理，不进入公开数据包。

```powershell
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all -- --check
```

Windows 原生构建需要 Rust、MSVC C++ 构建工具和 Windows SDK；生成 EXE 安装器另需
Inno Setup。具体环境、组包和管理命令见 [分发说明](docs/distribution.md)，
行为约定见 [设计文档](design/)。
