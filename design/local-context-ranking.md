# 本地候选质量：频次、近期与前文关联

## 范围与授权

本轮实现公共词权重、个人频次与近期偏好、有限前文搭配评分，并让评分参与整句搜索；不新增神经语言模型、不新增网络请求，不安装或替换开发机在用输入法。用户已允许在安全输入框有限读取光标前文。本文替代 adaptive-candidates.md 的生产路径每次相邻前移排序约定；旧排序记录可作为弱兼容信号，不得作为绝对顺序覆盖新评分。

## 评分及搜索

- 普通候选使用确定性整数评分：对数词权重、受限个人次数、受限近期偏好、前文搭配与明确的简拼/碎片惩罚。各项有界，稳定相同分数时保留确定性顺序；不把首次偶选永久置顶。
- 个人统计以规范拼音/原始词文本识别，不以 raw 简拼、显示简繁或候选序号识别。近期用锁内合并的提交序号而非系统时钟；随后续学习活动衰减，不声称按自然日衰减。
- 上下文同时包含已验证的宿主前缀与本次 confirmed 部分。进入搜索时使用同一份不可变评分快照，在路径扩展与剪枝前计算词衔接分，不仅重排最终八个候选。原始匹配、规范 reading、消耗和学习事件身份保持不变。
- 保持搜索、边枚举和输出有界。不能以减少分词数量的绝对排序压过更自然路径；分词惩罚进入综合分。全拼/简拼和候选来源语义不变。完整与部分候选分组、原生布局配额继续保留，各组内部使用新分数，不凭空生成词或把片段冒充完整候选。
- 首屏仅一条普通整句是展示配额，不是删除候选的授权。其他已召回整句保留在后续页可选择；合法完整混拼词不能被同文拼写建议替换其规范身份或学习事件。
- 公共搭配首期可从已锁定、已许可 flower-dict 词条内部相邻汉字生成有界的弱搭配先验，必须明确标为词表派生证据而非语料词频。无证据回退词频。不得手写用户例句排行榜、导入未经核实许可语料或修改外部词库仓库。个人词级搭配以确认过的相邻词及前文后缀为依据，限制记录长度与容量。

## 宿主前文与隐私

- 只在真实编辑会话内、已通过现有普通学习安全范围门禁的 context，读取当前折叠选区或当前 Flower composition 起点之前最多 32 个 Unicode 标量（读取缓冲最多 64 UTF-16 单元）。选区不折叠、焦点/代次不匹配、范围操作失败均使用空前文；不读取整个文档、剪贴板、密码或未知不安全范围。
- 获取文本前验证范围与安全门禁；断开的 UTF-16 代理对不作有损替换。以末尾连续汉字为有效后缀，在标点/换行等边界截断。不把宿主旧文与 confirmed 重复拼接，不将 preedit 当作已提交前文。
- 安全检查必须覆盖实际扩展的整个读取范围，不能只查询默认光标选区。范围内任一属性段敏感、未知不安全、枚举不完整或失败时不读取；普通当前选区的兼容兜底不能自动证明其前文也安全。
- 前文仅在本次组合内存中用于排序，不保存或记录原始段落。每次新组合重新取当前位置；外部光标/正文变更不能沿用旧前文，无法证明位置时降级。预测 OnTest 不读取正文、不改变真实学习状态。普通排序前文不得自动流入 AI 请求。
- 可持久化的搭配仅来自用户本次成功确认的普通词序列以及最多一个有界短汉字前文后缀，不保存段落。敏感/未知不安全 scope、失败提交、取消、AI/拼写/补全和 literal 提交不学习。清空学习删除所有新增统计；关闭停止新增并撤销旧批次，不偷偷删除已有数据。

## 持久化与发布

- 新 schema 向后兼容读取 1/2/3，新增字段默认空；只读加载不重写文件，旧版本拒绝新 schema。保留手工词、领域、显式开关、generation、旧计数和自动词。
- 一次成功编辑的所有统计复用现有 claim 一次性、安全范围、焦点/token/epoch/context generation 门禁，和同一个有界 worker/原子事务。锁内重读最新数据后合并频次、近期与搭配，跨进程不得丢增量。不得另开不受管理的数据文件或按键读盘。
- 新记录计入原 16MiB/100000 总预算，另设明确子预算与淘汰规则，批次先完整验证再应用。计数饱和、序号溢出必须确定性处理。排队/落盘失败按现有错误渠道报告，内存生效不代表已耐久保存。

## 实施顺序与验收

公共弱先验的容量裁剪不得按 Unicode 码位直接取前若干项而系统性丢弃靠后汉字。以不同词目内部支持度选择有限高支持搭配，最终按键排序供查询；支持度只是词表证据，不是自然语料出现次数，不能把多音读音行重复计为不同词目。

1. 扩展 engine/ranking 与 user_dictionary 的快照、学习事件和 schema；先锁定频次、近期、清空、迁移与并发语义测试。
2. 接入 decoder/session/router，生成可溯源的公共弱搭配先验；覆盖相同 raw 不同前文、confirmed 前缀、分词自然度与搜索剪枝前评分。
3. 接入 Windows 编辑会话的有限前文和成功发布学习，覆盖真实回调的安全/失败/预测/位置边界；不触碰实际用户词典、注册或在用 DLL。
4. 按差异运行 engine/学习/分页/原生受影响回归及严格 Clippy，记录实际命中数、版本与未覆盖项。使用固定样例分别衡量召回与首选/前三命中，不能把自定义夹具改善冒充真实用户质量提升。独立审查后仅补受影响证据。
