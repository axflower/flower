# 切换后首键不等待全词典初始化

## 问题与目标

0.5.4 首次真实拼音按键同步解压、解析约 175 万个拼音 key 的内置词典，
构造全拼、简拼、混拼索引；非空个人 overlay 还会复制基础词典并重建索引。
Release 固定开发探针观察到基础初始化约 8.9 秒。这不是等待输入法切换完成的
必要步骤，也不能通过延后到首键或简单提前到 Activate 解决。

本补充覆盖 `settings-resources-and-live-online-toggle.md` 中“首字母加载完整索引”
的实现约定，不改变词条、候选质量、隐私、安全安装路径或学习语义。

0.5.8 的紧凑索引表示及后台专用拼写种子见 `compact-builtin-index.md`，
在保持本页首次输入与快照边界的前提下进一步减少重复数据。

## 基础词典

- 将完整内置词典的解析、去重、常用词分类、全拼/简拼排序和混拼 trie 构建前移到
  Cargo 构建期。运行期直接查询嵌入的只读索引，不解压/解析 TSV、不构建全量
  HashMap/trie；不通过减少词条或仅加载小词库实现“立即可用”。
- 索引使用显式版本及确定性的定长整数/偏移编码，保持安全 Rust 的有界访问，
  不将原始字节强转成 Rust 对象；构建和运行读取共享格式定义。
  索引属于二进制内嵌构建产物，不读取或信任用户提供的索引文件。
- 完整保留原排序、权重、规范 reading、简拼、混拼和本地补全的遍历预算及稳定性。
  将基础词典构建算法保留为小 fixture 的等价性验证入口。
- 动态 TSV 和个人 overlay 只为自身构建索引。overlay 与不可变基础层共享而非
  复制基础全表，查询合并保持既有重复词取最大权重及所有候选通路的语义。
  学习/用户快照不得污染全进程基础索引；不是在每键重新构建小索引。
- Activate、OnTest、Tab、数字及快捷键仍不触发输入重工作；保留休眠 context、
  首字母真实安装以及引号/标点状态。不丢首键、不借空词典吞键、不后台回放键。

## 离线 AI

- 首次真实输入只排队一次 activation 级 AI 启动任务，整个安装安全检查及
  `AiClient::start` 在受控线程执行。普通候选和提交不等待 AI。
- owner 通过已有 timer 非阻塞轮询；须确认线程已结束才回收/join，完成前保持
  原候选。结果仅安装至原 activation，不因正常换 context 丢失该能力，也不得
  将旧 activation 结果发布到新 activation。
- worker 持有 DLL 存活计数，取消后丢弃结果并关闭/join 自己启动的 client；
  owner 安装 scheduler 时先取得新的存活登记再释放 worker 登记。
  AI 关闭不启动，失败保留原固定状态且不重复每键扫描；安全检查不跳过或放宽。
- deactivate 取消并 join，不能以 detached 线程换取卸载速度；在途不可打断的
  文件系统检查仍可能使退出等待，不能宣称所有系统 I/O 都有严格时限。

## 验证与边界

固定公开输入、隔离 Store 和自有 TSF 文档验证首键、完整提交、overlay、引号、
OnTest 纯预测、AI 延迟/失败/取消/单次尝试及 DLL 生命周期。
Release 新进程比较基础初始化和首键，不把进程首次使用误称为物理磁盘冷启动。
检查完整词典与旧解析器的候选和索引等价性，覆盖简拼/混拼、学习与补全。

不自动安装、注册、切换用户输入法、覆盖在用 DLL、注入全局按键或请求真实模型。
隔离测试不等于用户浏览器或所有目标硬件实测；新包交付与实际升级另行说明。

## 分发载荷预算

用户确认旧实验包对应代码已撤销，并授权清理 `dist` 后用当前源码重建。
分发版本为 0.5.7，不恢复已撤销修改。实测 Release DLL 为 283,596,800 字节，
settings 为 282,163,200 字节，register 为 386,048 字节；仅三个 PE 已超过旧
512 MiB 总载荷限制，另需保留完整词典来源和固定 AI 资产。

构建器和安装器将展开载荷总预算统一为 1 GiB；单文件及压缩 ZIP 上限仍为
512 MiB，AI 子载荷仍为 256 MiB。仅调整总预算，不放宽资产白名单、摘要、
路径或安装安全校验，不向小型合成测试复制大索引。实际新包必须重新完成验包。
