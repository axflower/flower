# 自定义模型 API：Chat Completions 与 Responses

默认启用润色、自定义快捷键及更换模型时保留用户启停选择，以
`custom-shortcuts-and-seven-candidates.md`为最新合同，覆盖本文相应旧关闭授权条款。

用户已明确选择同时支持两种协议，替代仅固定免费 GLM 的产品约束。
本文件覆盖此前设计中固定智谱地址、模型、密钥槽及告知的相应条款。
普通输入、离线纠错、500/800字、严格选区捕获、一次性安全写回均不变。

## 最新修订：明确应用、模型选择与简化设置

### 窗口与滚动补充

- 默认模型设置窗口按所在显示器DPI取约820×900逻辑像素，并夹入该显示器工作区，
  不固定为620×560物理像素；较小工作区仍保留纵向滚动和焦点可达，不强制最大化。
- 滚动与几何/字体布局分离。仅滚动时不创建字体、不测量全文、不重建控件，
  批量移动子控件、禁旧像素复制并统一父子重绘；滚动越界且位置未变时不重复重绘。
  对高精度滚轮保留不足一格的delta累计，避免整数除法丢失或非标准小增量跳动，
  不加入积压动画或每次滚轮同步重绘整个窗体。
- 高级区切换、尺寸/DPI变化才重建布局度量；卡片背景与控件使用同一布局快照，
  长说明换行后滚动也不得出现旧卡片残影。保留原生下拉滚轮行为、键盘导航、
  获取目录任务取消/关闭安全及用户已确认可用的DeepSeek连接语义。
- 焦点自动滚入仅响应实际焦点变化/键盘导航或必要布局变更，不在每条消息后无条件执行。
  鼠标滚轮/滚动条可将旧焦点控件滚出视口，后续timer/paint不能反弹到旧焦点；
  用真实投递消息经过模态循环验证，不只同步SendMessage或让父窗口获焦来回避。
- 自有窗口验证默认尺寸在96/144/192DPI和小工作区均有界，滚轮包含高分辨率、
  连续往返与边界，计数验证无字体重建；返回相同位置后与完整重绘比较客户区像素。
  这些是隔离证据，不冒充所有真实鼠标/多显示器/DWM体验。
- Coding Plan返回未被本地识别的HTTP错误时，展示HTTP数值以及可解析的纯数字
  服务商业务码（最多9位）；不显示原始message、响应正文或非数字code。
  提示套餐适用环境限制及标准API区别，不把所有500断言为套餐拒绝，
  不伪装工具、不自动换端点/密钥/模型、不增加重试。
  已知鉴权/额度/忙等本地分类保持，非Coding端点（尤其已可用DeepSeek）行为不变。

DeepSeek `https://api.deepseek.com`显示响应格式无效。仅凭现有泛化提示不能认定真实原因；

- 普通配置流程默认使用Chat Completions，适合输入法单次短文本且服务商兼容面广。
  Responses保留在“高级设置”，已有Responses连接不静默改变协议，须明确保存并使用。
- 模型ID仍是接口必需参数，不从密钥推测或默认替用户选择付费模型。普通界面改为
  “获取模型列表”及模型下拉，不要求手输ID；不支持标准目录的服务可在高级设置手动填。
  目录同步只证明目录请求成功，不代表模型能生成或费用/权限已确认。
- 仅用户主动点击获取时，以编辑中的规范HTTPS基址追加`/models`发送认证GET；
  不补`/v1`，不发正文或推理请求，不自动同步。标准`data:[{id:...}]`有界解析，
  最多512个唯一有效ID、256KiB响应，拒绝非法结构/ID，不泄漏服务商error/message。
  使用可取消异步任务，30秒总期限，关闭或目标编辑变更后取消并丢弃晚结果。
- 仅轮换密钥不等于更换模型：保留用户已经明确选择或手填的模型，
  取消旧密钥在途目录并丢弃晚结果，提示目录尚未经新密钥核验，不无条件清空模型。
- 输入的新密钥仅用于明确请求及后续明确保存，不提前持久化；未输入时，仅允许读取
  与当前编辑连接ID/规范基址/协议一致的已保存连接凭据，不能把旧密钥发往新目标。
  获取列表不要求已经选定模型，应独立验证连接元数据，不能造伪模型绕过验证。
- 主要动作改为“保存并使用”：必须有明确选定/手填的有效模型。提供新密钥时先安全
  保存到该验证目标的槽，失败不应用连接；未提供时验证该目标已有密钥，否则不应用。
  然后从最新Store合并连接并设置active_id，回读核对实际scope后才报告已应用。
  密钥成功但配置失败须明确部分成功，不宣称应用或推理成功，不回滚未知并发设置。
- 旧连接ID的凭据兼容按精确旧基址/协议绑定，选择同端点的其他模型可沿用同槽；
  该调整不跨服务商/基址/协议转发密钥。旧“不再提示”scope仍要求精确旧模型。
- 原独立保存密钥/当前连接复选框不再作为常规操作门槛；列表选择只切编辑对象，
  主要按钮语义明确。显示实际当前连接/模型，以及“未调用验证”，不把保存当推理成功。
  目标变化继续撤销旧发送偏好和润色授权，删除凭据保留原冻结目标/窗口归属复核。
- 主配置框采用与帮写一致的浅底、白色分组卡片、标题/正文/提示层级、强调主按钮，
  正常界面分“服务连接、选择模型、应用状态”；高级内容默认折叠。支持缩放、滚动、
  键盘和焦点自动可见，截图仅自有HWND，不采集桌面或真实凭据。
- HTTP400/404/405/422及其它请求错误显示安全HTTP状态并提示检查路径/协议/模型，
  5xx显示安全HTTP状态而不只“服务不可用”。智谱官方标准/Coding入口分别识别，
  模型不存在、套餐/密钥不匹配不得冒充模型繁忙。错误只保留数值/本地分类，不回显正文。
  DeepSeek若选择Responses须明确提示其常规接口应使用Chat，不自动重发或暗切协议。
- 官方资料已核DeepSeek常规入口为Chat；其Responses选择在本地明确拒绝并指向高级设置，
  不先读取密钥/发错接口。对精确官方DeepSeek Chat基址（根或/v1）添加已文档化
  `thinking: {type: disabled}`，减少短文本等待；不向任意兼容服务注入专有参数。
  智谱`/api/v1`为Coding Plan，官方套餐限制适用工具环境，Flower不伪装工具身份或
  承诺套餐额度可用，也不自动迁移其密钥到标准API；界面与帮助明确提醒。
  智谱标准与Coding错误均可做本地业务码分类，但自动退避仍只沿用标准入口的原规则。

本修订覆盖下文旧的“不抓取模型目录”和“两步独立保存密钥/当前选择复选框”的界面约定；
其余双协议、安全传输和授权边界不变。anywork自定义Explicit目录也可手填模型ID，
其默认路由与当前会话路由分离，不能以它的“保存”推导当前任务已应用。

## 配置与范围

- 支持最多16组连接，每组是配置名称、稳定ID、协议、HTTPS API基址、准确模型ID。
  一个连接对应一个模型；同一服务商的多个模型可建立多组连接。明确选择当前连接。
- `Settings.model_api: ModelApiSettings` 保存连接列表和 `active_id`，不保存密钥。
  旧配置缺字段时只读解释为原智谱连接，保留旧密钥兼容，不自动迁写用户文件。
- API基址不自动补`/v1`，仅去尾斜杠，按协议追加`/chat/completions`或`/responses`。
  基址不能填写最终请求路径。首期仅HTTPS、ASCII域名/IPv4及可选端口；
  不支持HTTP、IPv6文字地址、userinfo、查询、fragment、编码路径、反斜杠、
  空白/控制字符或点路径段。错误显示固定安全说明，不回显密钥/服务商正文。
- 仅HTTP/SSE文本生成，不支持WebSocket、原生Anthropic Messages、OAuth订阅登录、
  工具调用、图片、任意自定义header或自动模型目录抓取。付费由用户自行向服务商购买。

## 身份、凭据与授权

- 每个任务拿到已验证且不可变的连接快照。确认窗口显示实际基址、模型与协议；
  确认后再次核对当前连接，若已变化则取消本次操作，不能暗换目标。
- 凭据只进当前用户Windows凭据管理器。槽身份绑定稳定连接ID、规范基址及协议；
  不绑定模型名，允许同一连接同一端点改模型而不复制密钥。地址/协议变化必须重新输入。
  仅ID为legacy-bigmodel且地址、协议、模型与旧默认全部一致时使用旧BigModel槽。
  新建任意连接都不能自动读取旧槽。已有密钥不显示到编辑框、不写配置或日志。
- “不再提示”scope绑定连接ID、规范基址、协议、模型；旧智谱默认保持旧scope兼容。
  只有发送并勾选才保存；取消不保存；恢复仍立即清空偏好。
- 保存连接从最新Store合并单一字段，活动目标scope变化清除不再提示并关闭润色外发。
  主表单保存须保留最新连接、润色与发送偏好，不能以旧快照覆盖。
- 润色仍需明确勾选启用；使用激活快照中的连接，发送前核对最新Store中仍启用且
  目标scope一致，否则不发送并提示重新配置/切换Flower。不得为新目标沿用旧启用。
- 编辑器保存连接与保存/删除密钥是明确动作；密钥操作仅针对已保存且与编辑字段一致
  的连接。编辑未保存不能把密钥写到旧目标。删除连接不隐式删除凭据，提供独立删除动作。
  打开、选择、编辑、保存及删除均不调用推理API。

## 请求、响应与失败

- Chat使用模型ID、messages、stream及max_tokens；只有精确旧智谱配置保留其
  thinking disabled扩展，其他服务不得携带智谱专有参数。
- Responses使用model、instructions、input、stream、max_output_tokens和store:false；
  无previous_response_id/远程会话，无后台任务或工具。仅显示output_text的增量。
- Chat正常stop加[DONE]才完整；Responses只在response.completed且
  response.status=completed、输出含且仅含一个正常文本message，且无拒绝/工具/不完整时完整。
  核对完成快照与已累计文本一致；仅output_text.done或EOF不算完成。
  可有非可见reasoning输出项及明确列举的reasoning元数据事件，不展示、不拼接其内容；
  文本message的output_index不必为0，但所有正文事件须匹配同一message身份和索引。
  拒绝、工具输出、失败、不完整、截断、超限均不可应用。
- 沿用256KiB响应、32KiB事件、800字和UTF-8边界保护、90秒总期限、可取消及
  HANDLE_CLOSING前保留回调内存。TLS校验不关闭，重定向/隐式认证/cookie仍禁用。
- 智谱业务码分类仅用于智谱端点，其他服务以HTTP状态和固定错误分类处理。
  不自动切模型/账号，不自动开付费、不重发未知429；旧可选1302/1305有限重试
  仅用于明确智谱连接且无正文，不扩展到新服务。
