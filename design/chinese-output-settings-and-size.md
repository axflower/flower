# 简繁输出、候选窗设置入口与无损瘦身

## 授权与范围

用户选择“简体 / 通用繁体”，默认简体，不进行台湾词汇替换。
实现不安装、不注册、不修改真实用户配置或 Git 索引，旧 0.4.21 制品不覆盖。
emoji 当前仅为 Literal 目录收录，无内置拼音触发映射；本次说明该边界及
Windows `Win + .` 入口，不凭空将整个 Literal 目录或人工少量别名冒充完整支持。

## 简繁边界

提供 `ChineseScript::{Simplified, Traditional}`，序列化为
`simplified` / `traditional`。Settings 新增 `chinese_script`，缺省为简体。
设置页面提供两项选择，依照既有设置保存语义持久化，重新激活载入。
不改变 Shift 的中英文切换，不在正在编辑的宿主文档上执行全文转换。

转换采用固定 OpenCC 的 STCharacters/STPhrases、TSCharacters/TSPhrases 数据，
词组最长匹配优先、字符回退，多个映射值采用来源第一项；
仅执行 s2t/t2s，不采用地区术语表。保留原始文件、来源、完整 Apache-2.0 正文及摘要。
转换数据在进程内只初始化一次，按键不读磁盘、不重新建词库。

引擎保留原始 Choice、raw 消耗、读音、学习/排名身份及 AI 请求证明，
展示候选、已确认预编辑与实际提交使用同一目标字形。
对转换后相同文字、相同读音/来源类型、相同消耗的候选稳定去重，
保留已有顺序首项，分页依据转换后的真实显示文本。
AI/SP 必须先按原始请求及 proof 验证，再转换输出，不能用转换绕过证明；
显式选择后的普通学习仍使用原词条身份，AI/SP 不学习规则不变。
原始字母提交、标点、ASCII 与 emoji 字符串保持不变。
这里保留既有自定义普通词条的学习语义，不新增 emoji 触发词，
也不把自定义词典中的合法 emoji 候选改成新的“不学习”类别。
模式 setter 仅在空组词时生效；非空组词拒绝切换，旧票据不能选中新的显示。

分段选择必须使用完整原始 confirmed 前缀参与上下文转换。例如已确认“头”，
剩余“发”应显示“髮”而非“發”，最终提交“頭髮”。
显示投影和去重共用“转换(原始前缀 + 当前候选)”；
若转换结果保留当前已显示前缀，候选显示其后缀，否则候选显示完整转换结果，
明确呈现对未提交前缀的上下文修正，不能截取不存在的前缀。
AI 候选原本已含完整前缀，不能重复拼接。内部身份及原文不改变。

## 右侧设置入口

“输入框”按 Flower 自有非激活候选窗处理，不向宿主输入框注入控件。
候选窗右侧预留约 28 个逻辑像素按钮和间距，独立于候选、编号与 AI 状态行，
不恢复旧页脚。所有候选仍完整分页，不能仅少画尾项腾空间。
窄屏/DPI/长候选/滚动绘制和点击共用实际呈现的布局；
未成功呈现、旧 revision、隐藏/UIless 或尺寸已变不能授权点击。
按钮绘制齿轮或清晰设置标识，鼠标按下不激活，松开后延迟投递独立回调，
不进入候选选择/提交/学习链。提供按钮 hover/提示或可理解标识。

popup 提供独立 `set_settings_action_sink`，不扩候选选择动作协议；
Windows 激活接线核验当前 token/foreground/UI 可见性后，从本 DLL 同目录
的受保护完整安装启动 `flower-settings.exe`（无参数）。
使用精确绝对程序路径，不经 shell，不搜索 PATH，不提权；
启动失败给固定错误提示，不泄露输入，不自动修复安装或权限。
设置窗口取得焦点按既有失焦规则撤销候选/请求，不主动选词。

## 体积：先消除存储冗余，保留运行语义

不删词条、权重、AI 模型/ORT、许可正文或安全门禁，不改查询预算。
先采用可逆的内嵌 TSV 无损压缩：build.rs 从同一固定 flower-dict
DEFAULT_TSV 生成压缩字节，运行时第一次 builtin 初始化时解压后交给原解析器，
随后释放临时原文。使用纯 Rust miniz_oxide 0.8.9，保留 MSRV 1.75。
压缩只影响存储表示，原文大小与 SHA256 必须核验，损坏失败关闭；
OnceLock、共享索引、暖查询与克隆路径保持不变。
既有 DEFAULT_TSV 不应再被生产 PE 作为未压缩常量引用。

新增依赖仅 miniz_oxide 0.8.9 和 adler2 2.0.1，其他依赖不升级。
其 SPDX 的 Zlib 与 0BSD 完整正文已亲读，打包器可识别这两种 ID，
但正文仅接受此次精确原始 SHA（不凭文件名或标题）：
Zlib `0a54e647fe54104658b5e563c04c6f9edf251710e47bce692e0bd990a4ddaa39`，
0BSD `861399f8c21c042b110517e76dc6b63a2b334276c8cf17412fc3c8908ca8dc17`。
附带所有现有完整许可文件，增加截断/改条款失败用例，不改写原 SPDX。

外置扩充四文件原本用于交付/审计而非运行查词，可在新版本改为
`data/pinyin/vocabulary-audit.zip`：四成员、固定单层相对文件名、
无重复/额外/加密/链接，逐个展开尺寸与可信摘要保持原值。
审计 ZIP 压缩载荷不在安装时再展开，完整原始资料仍可离线取出。
打包器及安装器都验证内部成员，不信自签清单，限制外层与内层展开大小。
0.4.21 旧包四原文件继续只读兼容；新版本采用审计包形式并精确标记 manifest，
不能同时夹带两套或取消验证。其他旧数据资产与许可不动。
这里调整的是存储形式，不取消用户可获得的词库资料。

共享外置运行词库/预编译索引作为后续候选，不在未测情况下替换当前可靠架构。
安装器继续 solid LZMA2，ZIP 继续通用 deflate 9。
实际测量发现默认 8 MiB 字典对压缩后的重复内嵌词表无法跨 PE 复用，
同一载荷安装器反而达到 130916751 字节，因此不交付该初次容器。
最小满足重复跨度的标准 32 MiB 字典候选为 111480579 字节，
采用 `LZMADictionarySize=32768`；运行载荷逐字节不变。
这不是无成本优化：安装解压字典估计从 8 增至 32 MiB（多 24 MiB），
仅发生于安装阶段，不改变输入运行的模型、索引或查询参数。
未执行安装，不声称实测安装耗时或安装器总峰值内存不变。
不盲目继续增大字典、不采用 UPX、不减量化模型。

## 验收与交付条件

简繁测试覆盖中国/中國、头发/頭髮、发展/發展、软件/軟件、
全拼/简拼/混拼、重复归一、部分确认、完整提交、AI/SP及不学习、
旧设置默认和新设置往返。按钮覆盖 DPI、窄屏、旧帧、候选边界和独立回调。
压缩前后原文逐字节一致，保留原候选、权重、排序及失败门禁。
审计包正常及缺失/额外/路径/大小/hash/加密/损坏必须失败关闭。

同一 `lexicon_probe` 的基线已记录：冷初始化 18.303038 秒、
暖查询 p95 454500 ns、engine key p95 55964400 ns（一次运行，非硬件保证）。
优化版以同一负载复测并说明波动，不把文件变小等同于运行更快，
也不承诺任意机器零性能差异；若有实质回退，先修复或撤回相应优化。
功能/安全与性能证据完整后才构建新补丁制品并报告实际安装载荷及容器大小。
