# 0.5.17：选词反馈、日常排序与无损体积优化

## 用户目标与边界

用户报告 Edge 和文本编辑器中输入 `huiyi`、按数字 2 选择“回忆”，同框立即重输仍没有前移。
用户确认继续使用综合评分而非恢复绝对相邻交换，但希望一次选择能获得更明显的权重。
保留有限前文、公共词频和个人频次/近期组合；不对 `huiyi` 或某个例词硬编码排名。
普通成功选词才学习，敏感范围、失焦、失败/取消、原拼、AI/拼写/补全不学习的门禁不变。

## 个人与日常排序

- 先以真实 builtin 和隔离 Store、生产 TSF 数字选择复现，分别核对事件、内存评分、
  worker 保存、同框再输、fresh context 和新 Store 回读，不只测试保存接口。
- 增强近期成功选择的有界加分，让普通词之间的一次选择更容易改变顺序；随着后续学习活动
  衰减，不永久置顶，不让已选低频词无条件压过任意高频词和明确前文关系。
- 个人词近期上限从 96 提升至 320，次数的对数尺度从 24 提升至 32；前文搭配的现有
  独立加分不变。此范围用于提升普通歧义词的首次反馈，不承诺任意候选一次必到首项。
  序号溢出时的重基准窗口同步覆盖更长的近期衰减范围，保留仍有效记录的相对年龄；
  不因溢出额外撤销仍在窗口内的权重，也不复活已失效的记录。
- 默认排序继续从已固定词库的真实权重和已有日常分类获得证据。公共日常 prior 应是有上限的
  有限加分；保留既有日常层合同，新增交流词优先规则以规范读音和原始文本精确匹配，
  单词最多增加 128 分，明确是人工使用 prior 而非统计词频。不直接覆盖综合排序。
  不改真实词频或读音、不删候选、不扩搜索预算；不改变独立 flower-dict 的来源数据。
- 用执行前固定的日常全拼/简拼/混拼、单字及歧义控制集，分别报告首项/前三与完整召回；
  个人增强、默认质量和宿主学习分开取证，不承诺所有语境只有唯一正确顺序。

## 无损体积优化

- 安装器下载大小、ZIP 大小、单版本展开载荷与本机保留的旧诊断/备份各自统计。
  未获明确清理授权不删除旧目录；备份清理不冒充新包压缩收益。
- 在保持内嵌索引直接随机访问的前提下，尝试将字符串长度列改为按实际最大值选择的
  1/2/4 字节无符号整数，格式版本升级。偏移与 ID 完整保留，构建时验证无损和范围；
  损坏描述符、长度溢出与截断失败关闭，不增加按键解压、扫描、外置文件或全表初始化。
- 保留全部词条、规范读音、原权重及分类、索引候选顺序、固定模型/运行库和完整许可。
  不降低模型精度、不改首次联网下载、不用降低编译优化换体积。
- 必须用实际完整 ZIP/EXE 与同负载交错新进程时延验收；若收益不足或出现实质性能回退，
  不以原始索引变小宣称成功，可只保留有证据的优化。
- 可对同一已验证载荷另做 64 MiB LZMA2 字典的有界安装器对照。只影响安装阶段，
  明确相比当前 32 MiB 增加约 32 MiB 解压字典内存，不冒充输入运行时优化或总峰值测量。
  只有实际完整 EXE 收益值得该代价时才采用；不改模型、词库、程序或 ZIP 字节。
