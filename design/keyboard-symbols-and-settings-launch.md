# 0.4.23：齿轮入口、简繁快捷键、符号与设置启动

本轮增量覆盖 0.4.22 相冲突部分，不撤销已有简繁上下文投影、学习、
安全检查与无损词库存储。用户要求右侧仅设置图标、Ctrl+Shift+F 简繁切换、
修复 Shift 数字符号、设置无黑框并优化打开响应。保留旧制品，不自动安装。

## 齿轮入口

原设置按钮改为矢量齿轮，不再在按钮面上绘制“设置”文字，不依赖字体私有区
或缺失字形。沿用独立点击区域、延迟回调和已呈现帧授权，不改变候选编号、
总宽和分页预算；图标随 DPI 缩放、主题变化，居中且不越界。
可提供“设置”悬停提示，但不能以提示文本代替图标。

## Ctrl+Shift+F

仅在 Flower 激活且真实焦点/context 身份检查通过时识别精确组合：
Ctrl+Shift+F，无 Alt/Win。其它宿主快捷键仍直通，不注册全局热键。
OnTest 只预测；真实首个 F keydown 翻转一次，repeat 不重复翻转，
该组合不得触发单独 Shift 的中英文切换。英文状态下也允许切换输出字形，
但不因此退出英文模式。

快捷键作用于当前 Flower activation，跨该 activation 的 context 保持一致；
重新激活按设置页已保存的默认字形载入，不在按键中写磁盘。
这与设置页“保存默认字形”区分，文档须明确，不能偷偷覆盖用户配置。
组词中可切换：保留 raw、caret、原始 confirmed 段和原词身份，重新生成目标
字形候选/分页/预编辑，不提交、不学习或制造 promotion。
撤销旧候选票据和在途 AI 发布，后续请求按新 revision 正常生成。
设置初始化 setter 可保留空组词限制，新增专用安全 toggle 路径。

## Shift 数字与 ASCII 符号

修正 Shift+OEM_PLUS 为 `+`，不能翻页；未加 Shift 的 =/- 及既有小键盘翻页
契约不变。Shift+0..9、OEM 标点统一走既有键盘映射。
中文模式保留原中文标点：!→！，@/#/$/%/&/* 等无中文替代的符号原样输出，
^→……、_→——、括号/引号等仍按现有规则；+ 原样输出。
补齐 ASCII 标点/符号的消费路径，空组词时直接插入；
组词时按原标点规则先提交当前候选一次，再追加符号，不能吞符号或误选数字候选。
符号自身不产生学习；已有普通词的合法学习不因追加符号被扩权或误清除。
英文模式由宿主正常输出，Ctrl/Alt/Win 组合除本快捷键外仍不截获。
已支持的 ^ 也须通过生产按键路径回归，不能仅凭纯映射断言用户现场已修复。

## 无黑框与设置启动

设置 EXE 使用 Windows GUI 子系统，无参数 GUI 启动不创建控制台；
真正 CLI 在已有父控制台下可附着，但不能新建控制台；
已有重定向标准流须保留。帮助、错误退出码、词典 CLI 与 AI 服务协议不变，
AI/server/登录静默模式不得因附着控制台引入窗口或输出。
TSF 启动 GUI 仍显式使用 CREATE_NO_WINDOW，不经 cmd/shell/PATH 或提权。

按钮回调只做当前 activation/thread/foreground 检查并排队。
完整安装路径解析和整树 ACL/reparse/hardlink 校验在 activation 所有的单个
worker 执行；不缓存绕过安全检查，不因模型大小误删检查。
worker 只返回安全解析结果，所属线程以非阻塞 poll 取回并再次核 token/焦点，
仍有效才启动 GUI；失败在所属线程给固定错误。
连续点击 coalesce，一个 pending worker，禁止多次并发扫描或无限排队。
取消/停用后不启动旧结果；worker 必须取消并 join，join 结束前保留 DLL
ObjectRegistration，不能 detached 或从后台跨线程使用 Rc/COM/context。
允许复用 popup 已有 50ms idle 回调，但不得令关闭 AI 时设置完成事件不再处理。
spawn 本身保留在所属线程，慢检查不在其上执行。

设置 GUI 先创建显示首屏，再异步加载初始用户词典；UI 使用可见“正在读取”
状态，加载完成前禁用依赖词典的写操作。
失败明确报错并保留原文件，不能当空词典、自动重建或绕过写门禁。
worker 不持裸 HWND/窗口指针，不写真实 UI，结果由所属窗口/timer 消费；
窗口销毁需安全取消并 join，晚结果不能作用于复用 HWND。
既有设置读取、表单保存/立即词典开关/清空确认语义不变，GUI 不初始化 Lexicon
或模型。后续显式字典操作可复用原同步刷新，不扩大本轮为整个设置后端重写。

## 验收

定向覆盖数字键 Shift 映射、所有符号空/有组词真实提交、中文标点、
翻页及宿主快捷键直通；Ctrl+Shift+F 的 OnTest 纯预测、首按/repeat、
组合中 raw/caret/confirmed 保留、旧 AI/候选票据拒绝、不学习、
英文模式和真实原生 context 路由。
齿轮以自有窗口/离屏图验证 DPI/明暗主题、非空和边界，保留旧帧命中测试。
延迟校验 fixture 证明回调不等待 worker、关闭 AI 也能完成、取消/失败不启动，
保留不可信路径拒绝；延迟词典 fixture 证明首屏先显示、写控件受限及晚结果安全。
真实 release PE 子系统须为 GUI，并通过重定向 --help、CLI 参数/退出码测试；
不运行真实用户词典命令或实际启用/安装。
测量对象/负载/初始化阶段分别记录，不把模拟阻塞或原生 fixture 当用户现场耗时。
