# 本地打包与发布边界

用户已明确：以后修改完成后直接打包，但不要直接发布。

- 每次完成授权修改和相应验证后，直接构建当前版本的 Windows x64 完整
  ZIP 与 EXE 安装器，不再单独询问是否打包。
- 采用既有标准构建入口和完整固定资产，核对包内版本、说明、文件清单、
  哈希、图标及安装器与来源 ZIP 的关联后，交付到 `dist/`，附校验文件。
- 保留既有版本；同名冲突先核清身份，不静默覆盖。验证失败或环境受阻时
  如实说明，不把未完成的包当作已验证交付。
- 打包不等于发布、安装或注册。未经用户对发布的明确指令，不上传 GitHub
  或其它平台、不创建发布标签、不自动推送；也不自动运行安装器或改变输入法配置。
- 用户明确指定仅讨论、只改文档、只读或其它交付范围时，以该次明确范围为准。
